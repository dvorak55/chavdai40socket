## Chavdai40% Socket（ソケット）の特徴
 - デコレーションできる、コンパクトで健気なキーボード
    - 40％キーボードというサイズ感（キー数44、または42）
    - ソケット対応なので、とりあえず組み立てて後でデコレーションするのも可能です
    - キーボードケースが付属しているので、持ち運びしやすいです
 - リーズナブルなキーキャップが選べます
    - Amazonでも売っているキーキャップが使えます
    - ちょっと高価なキーキャップも、もちろん使えます
    - 日本語キーボードの縦長Enterキーは使えません
 - Vial（ヴァイアル）というソフトに対応しています
    - 40％キーボードでも数字と記号が入力できます
    - Ctrl＋a等の組み合わせを1つのキーに登録することも可能です
 - USB-Cでパソコン／スマホ／タブレットと接続して使えます

## 難しそうなポイント
### １．スタビライザーの取り付け
スタビライザーは、説明書にあるように大きな方の穴に爪を引っ掛けた後、小さい方の穴にもう片方の爪を嵌める手順で取り付けます。  
このスタビライザーを取り付けた後、キースイッチ・キーキャップを付けると、キースイッチがうまく戻らないことがあります。  
その場合は、キーキャップをつまんで、上下左右に動かしてみて下さい。 　
少し遊びができると、キースイッチがうまく戻るようになります。  
### ２．デコレーションの後に、キースイッチ・スタビライザーを取り付ける
おもて面にデコレーションのシール・シートを貼ると、キースイッチ・スタビライザーを取り付ける時、少しキツくなります。  
簡単にするため、キースイッチ・スタビライザーの取り付け箇所のシール・シートに、あらかじめ鉛筆やボールペンで穴を空けておくと良いです。
また、デコレーションを3枚ほど重ねた箇所のスイッチ取り付けはかなり辛いので、その場合は、スイッチの穴の箇所だけデコレーションを破いて取り除くと良いです。
