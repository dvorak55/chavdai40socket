# Chavdai40 Socket  

![chavdai40s](https://github.com/dvorak55/chavdai40/blob/master/image-ver1/impl-1.jpg)

Chavdai40 Socket is very simple decoratable 40% keyboard

* Keyboard Maintainer: [t-miyajima](https://github.com/dvorak55)
* Hardware Supported: Chavdai40s PCB socket version.
* Hardware Availability: [yushakobo](https://shop.yushakobo.jp/collections/regular-keyboards/products/18395)

Make example for this keyboard (after setting up your build environment):

    make chavdai40s/rev1:vial  
    make chavdai40s/rev2:vial  

Flashing example for this keyboard:

    make chavdai40s/rev1:vial:flash  
    make chavdai40s/rev2:vial:flash
